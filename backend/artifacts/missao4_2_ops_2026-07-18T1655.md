## Bugs reais (≠ ajuste de teste)

### BUG-4.2-01 (P0) — bloqueador

**Cancelamento DINHEIRO falha quando `caixas.saldo_atual` < valor estornado**

- RPC `cancelar_venda_transacional` (mig. 248 / 229) faz:
  - `UPDATE caixas SET saldo_atual = saldo_atual - v_valor_estornado`
  - com guard `(saldo_atual - estorno) >= 0`
  - senão `RAISE CANCELAR_VENDA_SALDO_CAIXA_INSUFICIENTE`
- RPC de venda `finalizar_venda_transacional_canonica_v4` **não incrementa** `saldo_atual` (já observado na Missão 4.1: financeiro do turno = `vendas_pagamentos` + `calcular_valor_sistema_dinheiro_caixa`).
- Neste teste: `saldo_atual=0`, estorno=`100` → cancelamento **impossível** sem intervenção manual no saldo.

**Impacto operacional:** operador/gerente não consegue cancelar venda DINHEIRO em caixa com `saldo_atual` zerado/desatualizado, mesmo com esperado de caixa refletindo a venda.

**Não é ajuste de teste:** forçar `UPDATE caixas SET saldo_atual = …` invalidaria o critério “não ajustar saldo manualmente” e mascararia o gap de produção.
